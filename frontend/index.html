🔌 Integración con Jan

El backend expone el mismo contrato que Jan consume para un proveedor OpenAI-compatible: GET /v1/models para descubrir el modelo y POST /v1/chat/completions con streaming SSE. Ambos viven en el mismo origen que esta consola, así que no hay CORS de por medio.

1 · Añade el proveedor en Jan

  1. Abre Jan → Settings → Model Providers → Add Provider.
  2. Formato de API: OpenAI-compatible.
  3. Rellena los campos de abajo (el botón copia el valor).
  4. Jan consultará /v1/models al guardar y listará servicenow-multiagent.
  5. Selecciónalo en el chat de Jan y conversa con el sistema multiagente.
